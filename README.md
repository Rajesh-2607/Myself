## 👤 Face Detection & Clustering System

**Tech Stack:** `Python` `PyTorch` `MTCNN` `InceptionResnetV1` `DBSCAN` `t-SNE` `UMAP`

An automated pipeline for face detection, embedding extraction, clustering, evaluation, and identity organization.

### Pipeline

```text
Images
   ↓
MTCNN Face Detection
   ↓
InceptionResnetV1
   ↓
512-D Face Embeddings
   ↓
Clustering
   ├── DBSCAN
   ├── Hierarchical Clustering
   └── Chinese Whispers
   ↓
Evaluation
   ├── Silhouette
   ├── NMI
   └── ARI
   ↓
Identity Organization
```

### Results

- Processes **1,000+ images per run**.
- Achieved **90%+ grouping accuracy**.
- Automatically organizes results into identity folders.
- Reduced manual sorting effort by **100%**.
- Generates t-SNE / UMAP visualizations.
- Handles variations in lighting, angles, and occlusions.
